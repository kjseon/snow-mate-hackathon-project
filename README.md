# SNOW-MATE

🏆 Kiro 대학생 문제 해결 해커톤 최우수상 수상 프로젝트

## 프로젝트 소개

SNOW-MATE는 공모전, 팀 프로젝트, 해커톤 참가자를 위한
AI 기반 팀 매칭 서비스입니다.

기존의 댓글, 오픈채팅, 지인 소개 중심의 팀원 모집 과정에서 발생하는
비효율성과 팀원 간 성향 불일치 문제를 해결하고자 기획하였습니다.

## 주요 기능

### 1. AI 기반 성향 분석

- 사용자의 협업 성향 분석
- 리더형 / 팔로워형 성향 파악
- 프로젝트 선호도 조사
- AI 기반 팀원 추천

### 2. AI 아바타 시뮬레이션

- 사용자 성향 데이터를 기반으로 AI 아바타 생성
- 가상 프로젝트 상황 시뮬레이션 수행
- 예상 협업 방식 분석
- 팀워크 리포트 제공

### 3. 팀 매칭 시스템

- 성향 시너지 분석
- 포지션 밸런스 고려
- 팀 구성 자동화
- 매칭 결과 제공

### 4. 서비스 내 채팅방

- 매칭 수락 시 자동 채팅방 생성
- 팀원 간 즉시 소통 가능
- 별도 오픈채팅 생성 과정 제거
