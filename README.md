# SNOW-MATE

🏆 2026 AI 해커톤 대회 (Kirothon for AI : Outthinkers Sookmyung) 최우수상 수상 프로젝트

## 프로젝트 소개

SNOW-MATE는 공모전, 팀 프로젝트, 해커톤 참가자를 위한 AI 기반 팀 매칭 서비스입니다.

기존의 댓글, 오픈채팅, 지인 추천 중심의 팀원 모집 과정에서 발생하는 비효율성과 협업 성향 불일치 문제를 해결하기 위해 기획하였습니다.

사용자의 협업 성향을 분석하고, AI 아바타 시뮬레이션을 통해 실제 협업 상황을 예측하여 최적의 팀 구성을 지원합니다.

---

## 문제 정의

기존 팀원 모집 방식은 다음과 같은 문제를 가지고 있습니다.

- 댓글 및 쪽지를 통한 비효율적인 팀원 모집
- 연락 두절 및 중도 이탈 문제
- 협업 성향이 맞지 않는 팀원과의 갈등
- 적합한 팀을 구성하기 위한 객관적인 기준 부족

SNOW-MATE는 이러한 문제를 AI 기반 분석과 시뮬레이션을 통해 해결하고자 하였습니다.

---

## 주요 기능

### 1. 협업 성향 분석

- 리더형 / 팔로워형 성향 분석
- 협업 스타일 프로파일링
- 프로젝트 선호도 조사
- 사용자 프로필 생성

### 2. AI 기반 팀 매칭

- 성향 시너지 분석
- 포지션 밸런스 고려
- 팀 규모 조건 반영
- 최적 팀 자동 추천

### 3. AI 아바타 시뮬레이션

- 사용자 데이터를 기반으로 AI 아바타 생성
- 가상 프로젝트 회의 시뮬레이션 수행
- 예상 협업 방식 분석
- 팀워크 리포트 제공

### 4. 서비스 내 채팅방

- 팀 매칭 수락 시 자동 채팅방 생성
- 별도 오픈채팅 생성 과정 제거
- 팀원 간 즉시 소통 지원
